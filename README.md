## 🛑 What is this?

**Tab Hoarder Therapy** is a lightweight, highly functional, and extremely judgmental browser extension. 

We all do it: opening 45 tabs telling ourselves *"I'll read this later"*. Your RAM is crying, your CPU is overheating, and you haven't done any actual work. This extension monitors your open tabs in real-time. The moment you exceed your self-imposed tab limit, it hits you with a passive-aggressive system notification to remind you to focus.

## ✨ Why You Need It (Features)

- 🕵️ **Real-Time Tab Stalking:** Uses the `chrome.tabs` API to instantly know when you open *yet another* tab.
- 💅 **Sassy Notifications:** Leverages the `chrome.notifications` API to deliver randomized, sarcastic reality checks.
- 🎨 **Premium Dark Mode UI:** A gorgeous, glass-morphism dashboard that updates live.
- ⚙️ **Instant Auto-Save:** Powered by `chrome.storage.local`. Change your limit, and it saves instantly.
- 🚨 **Visual Guilt Trips:** If OS notifications are blocked (DND), the extension icon badge turns bright red just to stare at you.
- ⏸️ **"Leave Me Alone" Switch:** A pause toggle for when you *actually* need 30 tabs for research (yeah, right).

## 🛠️ The Geeky Stuff (Tech Stack)

Built from scratch to demonstrate a deep understanding of browser architecture, zero-dependency engineering, and modern DOM manipulation.

- **Languages:** Vanilla JavaScript (ES6+), HTML5, CSS3 
- **Frameworks:** Absolutely zero. (We don't need React for a popup, Brenda).
- **Architecture:** Chrome Extension Manifest V3
- **APIs utilized:** `tabs`, `storage`, `notifications`, `action`, `runtime`

## 🚀 How to Install (Developer Mode)

Since we haven't unleashed this monster on the Web Store yet, here's how to install it locally:

1. Clone or download this repository.
2. Open Chrome or Brave and navigate to `chrome://extensions/`.
3. Toggle on **"Developer mode"** in the top right corner.
4. Click **"Load unpacked"** and select this folder.
5. Pin the extension, open the dashboard, and set your limit. 
6. Start opening tabs and prepare to be judged.
